# Eve Sandbox Community

Start with **COMMUNITY-SETUP.md**. It has every step: Firebase project (sign-in), D1 database, R2 bucket, GitHub, Cloudflare, the secret, and making yourself moderator.

Quick map: `public/` is the website, `worker/index.js` is the server, `schema.sql` creates the database tables (paste it into the D1 Console; `migration-profiles.sql` is only for a database made before profiles), and `wrangler.jsonc` is the only file you edit (your three Firebase values and D1 database ID).
